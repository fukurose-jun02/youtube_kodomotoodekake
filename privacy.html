プライバシーポリシー

最終更新日：2026年10月30日

「こどもとおでかけ」（以下「本サイト」）は、運営者の家族が撮影した動画を、家族や知人が見返すための個人用の動画一覧サイトです。本ページでは、本サイトにおける情報の取り扱いを説明します。

1. 本サイトが利用するGoogleのサービスについて

本サイトの動画一覧は、運営者自身のYouTubeチャンネルの情報を、YouTube Data API を通じて取得して作成しています。この取得と更新には、運営者本人だけが使う同期用のツール（以下「本ツール」）を使っており、本ツールは Google の OAuth 認証で運営者本人のアカウントにのみアクセスします。

2. 取得する情報と利用目的

  • 取得する情報：運営者のYouTubeチャンネルの動画の情報（タイトル、説明文、投稿日、サムネイル、動画ID、再生時間など）
  • 利用目的：本サイトの動画一覧の作成と更新、および動画の分類（カテゴリのタグ付け）のみ

本ツールは、運営者本人のアカウント以外の第三者の個人情報を取得しません。

3. 情報の保管と第三者への提供

  • 取得した動画の情報は、本サイトの表示に必要な範囲で、運営者の管理するリポジトリと本サイトの公開ファイルに保存します。
  • 認証に使うトークンは、運営者のパソコン内にのみ保管し、公開しません。
  • 取得した情報を、広告、販売、分析その他の目的で第三者に提供・販売することはありません。

4. Google API サービスのユーザーデータに関する方針

本ツールによる Google API から受け取った情報の使用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。

5. 本サイトの閲覧について

本サイトでは、閲覧者の氏名やメールアドレスなどの個人情報を、収集・保存しません。動画は YouTube の埋め込みプレーヤーで再生されるため、再生時には YouTube（Google）の利用規約とプライバシーポリシーが適用されます。

6. 連携の解除

運営者は、Google アカウントのアクセス権の管理ページから、いつでも本ツールの連携を解除できます。

7. 方針の変更

本ポリシーの内容は、必要に応じて変更することがあります。変更した場合は、本ページの最終更新日を改めます。
