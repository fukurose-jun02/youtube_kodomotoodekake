###### 順番の理由
- 手順2・5は、キーが無くても進められる（Geminiの代わりを差し込んで確認する）。ユーザーの作業（手順3・4）を待たずに、先に進める

###### リスク
- 共有キーの残高切れ：バーチャルトークも止まる。上限（全体1日50回）と、手順8の確認で抑える。残高は、AI Studioで事前に確認してほしい（10/17時点で ¥800 を追加。現在の残高は未確認）
- 使われすぎ：URLが広まると上限に早く達する。そのときは、上限値を調整する（または、合言葉を足す）
- 回答の質：実際のGeminiで試して、指示文を調整する
- Free枠：Workers Freeは1日10万リクエスト、CPU 10ms/リクエスト（待ち時間は含まない）。D1 Freeの書き込みは1日10万行。この規模では十分（実装前にドキュメントで再確認する）
